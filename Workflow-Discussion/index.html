So what makes a good workflow?

My main function for this work flow follows a couple of guidelines :

  • Speed, everything should be one or two key presses away.
  • Durability, everything must be consistent and resilient to changes.

So here’s the stack I’ve settled on :

Problem Solution
Windows i31
Text Editing Neovim
Terminals Kitty
Sessions Tmux

After experimenting with a few window management options like OXWM, DWM, and Hyprland I’d ultimately end up settling on i3. For a couple reasons :

  • i3 is so simple to configure, DWM required tons of recompilation and was thus incredibly slow to iterate with. Whenever I wanted to test another change or breakout window it would require tons of patching and modification in Xephyr. I3 on the other hand allows for 90% of it’s config to be done on a singular file and it’s api is incredibly accessible for simple shell scripting to control the rest of it’s behavior.
  • I dislike wayland because it’s too new for not much gain, the time I’d need to invest into learning wayland doesn’t seem to offer many real advantages. Sorry Niri fans
  • The tiling on i3 just flows best with my way of thinking, especially with a small autotiling script I wrote. The manager allows for a great mix of program based workspace pinning, automatic tiling, and gaps / vanity features with picom

Using Neovim follows pretty intuitively. I am not smart enough to use emacs, and large electron based apps like vscode are terrible for battery, performance, and aura. I’ve included my repo that contains a few interesting editions etc, I’ll likely write a more indepth explanation of this in the future.

There’s not much of a reason for kitty, it was honestly the first terminal emulator I used and it always worked well. Never really found a reason to go out and find a new terminal emulator. It also has a very nice color api!

Tmux is used for 2 things, multiplexing in kitty and session persistence. I use the splitting in Tmux because it handles the text movements and artifacting even better than the native panes. But the main benefit of Tmux comes from it’s session persistence combined with searchable sessions. I write extensively about this in my post here
