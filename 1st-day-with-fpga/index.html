The first day with the Tang Nano 9K

2026–03–28

Getting started!

Link to all code

So the board has arrived! But I can’t be bothered to use the proprietary IDE / toolchain that the brand provides. So instead, I’ll be using the oss-cad-suite to generate bitstreams then openFPGALoader to program the Tang Nano.

But in other news, I was able to get the whole thing working and get a nice blink / counter on the FPGA. Next up will be properly soldering it and tying it to some LED’s on a breadboard.
